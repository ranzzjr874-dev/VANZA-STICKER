VANZA STICKER BACKEND

Paket ini mengubah gambar yang dipilih dari HP menjadi WebP 512x512 melalui backend Node.js.

Deploy:
1. Unggah isi folder ini ke repository GitHub.
2. Buat Web Service di Render dari repository tersebut.
3. Build command: npm install
4. Start command: npm start
5. Buka URL Render yang diberikan.

PENTING:
- Aplikasi ini belum mengambil gambar langsung dari tautan komentar TikTok.
- Link komentar bukan otomatis URL file gambar; pengambilan langsung perlu akses sumber media yang tersedia dan sesuai izin.
- Hasil WebP perlu diimpor ke aplikasi pembuat paket stiker WhatsApp yang kompatibel.
